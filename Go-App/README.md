# Borgs Motorcycle – Go's Module (Product Catalog + Cart)
React frontend + Spring Boot backend.

## Run
1. Backend (Java 17+, Maven):  cd backend && mvn spring-boot:run   -> http://localhost:8080/api/products
2. Frontend (Node 18+):        cd frontend && npm install && npm run dev  -> http://localhost:5173

Start the backend first. Database: H2 in memory (resets on restart). See application.properties for MySQL.
